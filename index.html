How to use this page
  1. Every time you open this page it checks the Materials Request form and adds any new answers, so the list is always current. Tap Refresh next to the date to check again. It also rebuilds every Thursday morning after the form closes. Pick another Sunday from the "Week of" menu if you need it.
  2. Preview: open this early in the week, before forms come in. It shows every activity teachers can pick for the Sunday you choose and what each one needs. Switch to Everything, by closet to see what we don't have yet so you can order early.
  3. Headcounts: fix any room marked "Needs a number." Every quantity on the page updates when you change a headcount.
  4. Print: one packet per room. Tap Save packet, open it from your downloads, and print the whole file two-sided one time. The cover sheet says which room it belongs to. Rooms with cardstock activities also get a small cardstock packet. The first Sunday of each month adds a Memory Verse page for every room. Need to reprint one thing? Switch to By activity.
  5. Pull: items are grouped by closet. Check each one off as you pull it. If it isn't where the page says, tap Found it in… or Can't find it. That's how the inventory learns.
  6. Breakroom bins: one card per room, sorted by hour. Check off each item as it goes in the bin. The bin turns green when everything is checked.
  7. Order & follow up: anything we're out of or couldn't find, teacher requests that need a person, and rooms that haven't turned in the form.
  8. Closet map: search any item to see which closet and shelf it's on. Yellow "confirm" means I couldn't be sure from the photos. Check it once and tap Found it in… so it turns green.
  9. Bibles, coloring supplies and writing supplies are already in every room, so they never show up here. Phones and music are on the teacher.
