# JF Kids Sunday Pull List

The page volunteers open to pull materials, fill bins and print packets each Sunday.

- Each person opens their own link: `https://jfkids.github.io/pull-list/?key=THEIR-KEY`. Links come from the People & links tab.
- This page holds no data. Checkmarks, headcounts, inventory, people and the log live in the "Pull List App Data" Google spreadsheet, and every request is checked against the person's key by the Google Apps Script server.
- To update the design, replace `index.html` with a new build.
